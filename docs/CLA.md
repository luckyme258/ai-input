# 贡献者许可协议（CLA）说明（草案）

## 目的
确保社区提交的代码、词库与文档由项目统一按 AGPL-3.0-or-later 授权，避免后续有人对自己贡献的部分另授商业许可，导致主协议被分流。

## 提交即视为同意（草案要点）
1. 你声明对所提交内容拥有合法版权，或有权按本协议授权。
2. 你授予项目维护者对贡献内容的永久、全球、免费、可再许可的权利，用于复制、修改、合并、发布与再授权。
3. 贡献内容默认按 **AGPL-3.0-or-later** 与主项目同协议发布；数据词条按 `data/` 目录标注的协议发布。
4. 你保证贡献内容不侵犯第三方版权、商标或隐私；如引入第三方件，须在提交说明中标注其原始协议。
5. 项目保留对特定合作方另行签发商业许可的权利；这不改变对外默认的 AGPL 授权。

> 正式启用前，本草案需由项目维护者定稿；涉及法律条款建议咨询专业律师。
