# 词典合规审核手册

> 适用范围：`data/dict/` 下随安装包分发的全部 TSV 词库。
> 目的：在词库重生成、换源、扩词时，按统一口径审核并剔除不宜上屏的词条，避免违规。
> 本手册只记录**分类口径、流程与机制**，不在仓库内罗列具体敏感词条。

## 1. 基本原则

- 本地优先：学习数据只存本机；但随包分发的**静态词库**会被所有用户使用，分发前必须过审核流程。
- 代码协议（AGPL-3.0-or-later）不自动覆盖数据；各上游数据按自身 MIT 等协议分发，LICENSE 原文随包保留（见 `data/dict/LICENSE.*`）。
- 审核结论以**人工复核**为准；脚本只做语素归类与候选抽取，不做最终定性。
- 剔除表、审核清单等含敏感词面的文件一律放在 `data/local/`（已 gitignore），**不提交、不推送、不随包分发**；公开仓库内只保留已审核通过的成品 TSV。

## 2. 当前词库与过滤链路

| 词库文件 | 上游来源 | 协议 | 当前规模 |
|---|---|---|---|
| `common-mit.tsv` | fxsjy/jieba `dict.txt.big` + mozillazg/pinyin-data | MIT | 约 7.87 万简体词条 |
| `hsk-basic.tsv` | drkameleon/complete-hsk-vocabulary | MIT | 约 1.26 万词条 |

`common-mit.tsv` 生成顺序（见 `tools/Convert-CommonDict.py`）：

1. 仅保留中文词，词频 ≥ `min-freq`（默认 20），长度 ≤ `max-len`（默认 6 字）；
2. 多音字取首读音，剥声调号，ü/ǖǘǚǜ → `v`；任一汉字查不到拼音则跳过；
3. **繁体剔除**：zhconv 转简体后与原词不一致即跳过（`--keep-traditional` 可关闭，默认开启）；
4. **合规剔除表**：命中 `--blocklist` 指定词表即跳过；
5. 同词去重保留最高词频，按词频降序输出。

## 3. 分类口径与当前处置

审核时把候选词归入下列类别，再决定保留或剔除。

| 类别 | 口径 | 当前处置 |
|---|---|---|
| 党务政党 | 政党组织、机构、身份、党务活动相关词 | **剔除**（纳入剔除表） |
| 政权历史 | 政变、叛乱、割据、傀儡、汉奸、卖国、复辟、权臣酷吏等政权更迭与历史定性词 | **剔除**（纳入剔除表） |
| 意识形态阶级 | 阶级斗争、革命/反革命、主义思潮、压迫剥削、殖民等意识形态定性词 | **剔除**（纳入剔除表） |
| 政府政务 | 政府、政策、政体、行政、立法、司法、财政、机关等治理类通用词 | **暂保留，待后续复核**；其中专名与通用治理词需二次区分 |
| 军事战争 | 军队、武器、战役、战略、边防等普通军事词 | 保留（日常通用，不整类剔除） |
| 国家主权 | 国家、边界、领土、外交、条约等普通词 | 保留（日常通用，不整类剔除） |
| 法律司法 | 法律、法院、诉讼、刑罚等普通法律词 | 保留（日常通用，不整类剔除） |

说明：

- 后三类是按单字词根扫出的候选，其中绝大多数是日常多义词（如军人、法律、国家），不整类删除；如出现具体不当专名，按词条逐条加入剔除表。
- 人名、具体历史事件名等专名不内置匹配表；审核时若在候选清单中发现，逐条人工判定后处理。
- 多义词按**最常用义项**归类；若某词既有通用义又有敏感义，默认剔除并在审核记录中标注。

## 4. 剔除表机制

### 4.1 文件位置（本地、不入库）

- 剔除表：`data/local/src/blocklist-political.txt`，逐词一行，`#` 开头为注释。
- 审核候选清单：`data/local/src/political-review.tsv`（脚本抽取的待审列表）。
- 上述目录已被 `.gitignore` 排除，`git status` 不应出现这些文件。

### 4.2 转换器接入

通用词库（Python）：

```
python tools/Convert-CommonDict.py \
  --jieba data/local/src/dict.txt.big \
  --pinyin data/local/src/pinyin.txt \
  --out data/local/src/common-new.tsv \
  --min-freq 20 --max-len 6 \
  --blocklist data/local/src/blocklist-political.txt
```

HSK 词库（PowerShell）：

```
pwsh tools/Convert-HskDict.ps1 \
  -Source <complete.json> -Out data/dict/hsk-basic.tsv \
  -Blocklist data/local/src/blocklist-political.txt
```

两份词库使用**同一份剔除表**，避免通用表剔除、基础表仍残留的不一致。

### 4.3 候选清单抽取

`data/local/src/extract-political-review.py` 按第 3 节语素归类，输出 `political-review.tsv`（列：词条、拼音、词频、类别）。该脚本只用于生成待审候选，归类结果必须人工复核后再写入剔除表。

## 5. 复审流程（换源 / 扩词 / 定期复核）

1. **取源**：新上游词表放入 `data/local/src/`，保留原始 LICENSE 与来源说明。
2. **抽取候选**：运行 `extract-political-review.py` 生成按类别分组的候选清单。
3. **人工复核**：逐类核对，重点看党务政党、政权历史、意识形态阶级三类；政府政务类标注待复核项。
4. **更新剔除表**：把确认剔除的词条写入 `blocklist-political.txt`（一行一词）；不把清单整表入库。
5. **重生成 TSV**：按 4.2 命令重生成两份词库，覆盖 `data/dict/`。
6. **校验**：
   - 剔除表词在两份成品 TSV 中 **0 残留**；
   - 每行 4 列，拼音/首字母非空，无坏行；
   - 常用通用词未被误删（政府、政策、法律、国家等抽样保留）。
7. **构建与测试**：`dotnet build` 0 警告 0 错误；`dotnet test` 全绿。
8. **部署复测**：发布到 `dist/`，拷贝 `data/dict/*`，注册并重启 `ctfmon`，真机确认召回正常、无卡顿闪烁。
9. **提交**：只提交成品 TSV、转换器脚本与本手册；剔除表与候选清单保留本地。

## 6. 注意事项

- 新增上游词表前，先确认其协议与可分发性；copyleft 数据（如 CC BY-SA、GPL）需单独评估，不得直接并入 AGPL 代码库而不标注。
- 剔除表是本地合规资产；若公开仓库被他人 Fork，他人自行从上游重转时可能不复现剔除结论——因此**成品 TSV 本身就是已审核交付物**，不能只依赖本地剔除表。
- 政府政务类为当前已知待办：下次复核时区分通用治理词与不当专名，再决定是否扩充剔除表。
- 如发现已发布版本中存在漏网词条：先从本地剔除表补录，重生成并重新发布，再在更新日志中说明词库已复审。
